# CarCareLog Product Risk Register

The [native matrix](https://cloud.innoslate.com/cornell/p/746/diagrams/risk/318543) represents five system risks. The team supplied the likelihood, cost, schedule and technical ratings for those risks. A rounded equal-weight mean of the three impacts gives consequence, and consequence multiplied by likelihood gives the risk score.

| Risk | Model trace | L / cost / schedule / technical | Consequence / score | Control and evidence |
|---|---|---|---|---|
| [R1](https://cloud.innoslate.com/cornell/p/746/database/entity/318550) Well-formed but incorrect model output | UC.1, UC.4, F.2.2.2/3 | 1 / 1 / 1 / 1 | 1 / 1 | **Contain and review.** F.2.2.2 checks each drafted value against the receipt text and flags values that are not printed, a cost not printed next to the total, an odometer reading without a unit, and every category. The page highlights them and nothing is saved before Confirm & save. Tests: `test_draft_requires_review_and_does_not_write`, `test_FCS_1_4_2_well_formed_but_wrong_values_are_flagged_for_the_owner`, and `test_receipt_review.py`. `tools/evaluate_receipts.py` counts wrong values shown as found on the 20 labeled receipts. |
| [R2](https://cloud.innoslate.com/cornell/p/746/database/entity/318551) Runtime slow or unavailable | F.2.2.2, C.2.2, IC-03, FCS.2.1.2 | 1 / 2 / 2 / 2 | 2 / 2 | **Mitigate with a fallback.** The transport timeout (60 seconds by default) reports HTTP 503, proposes no record, and the page leaves the form for manual entry. `test_R2_runtime_timeout_preserves_ledger_and_manual_save` exercises this path through HTTP and isolated SQLite, and `tools/smoke_test.py` repeats it against a separate app process. The evaluation report records cold-start and warm latency for the pinned model. |
| [R3](https://cloud.innoslate.com/cornell/p/746/database/entity/318552) Untrusted receipt text reaches the prompt | UC.1, F.2.2.2, IC-03 | 1 / 1 / 1 / 1 | 1 / 1 | Input is bounded to 4,000 characters and sent as a JSON string that the prompt calls data. The output schema and the value checks do not depend on the text's instructions; a total mentioned inside an instruction is not accepted as the cost. Sample R09 in the labeled set contains an injected instruction, so the evaluation measures the real model on it. |
| [R4](https://cloud.innoslate.com/cornell/p/746/database/entity/318553) Unintended data egress | F.2.2.2, C.2.2, Ext.2, IC-03 | 1 / 1 / 1 / 1 | 1 / 1 | Application transport is fixed to loopback and sends no vehicle ID or historical ledger. Confirm daemon local-only mode and network telemetry before processing private data. |
| [R5](https://cloud.innoslate.com/cornell/p/746/database/entity/318554) Lost or misattributed confirmed event | UC.1, F.2.2.3, C.3 | 1 / 1 / 1 / 1 | 1 / 1 | Existing confirmation, transaction and response tests cover selected vehicle context and persistence. The single-owner demo has no production owner authentication. |
| Product detail P1. Schema changes with a model upgrade | R1 and R2, F.2.2.2, IC-03 response contract | Included in parent risks | See parent risks | Check candidate field set, service category, date, mileage and cost. Require contract regression and malformed-response tests before a model upgrade. |
| Product detail P2. Runtime or model dependency is abandoned | R2, Ext.2, C.2.2 | Included in parent risk | See parent risk | Review version and release support before an upgrade. Keep the manual path independent and fall back if the runtime cannot respond. |

At integration and before release, run the timeout fixture and check HTTP 503, zero accidental writes, and a successful manual save. During local runtime evaluation track timeout count, latency distribution, invalid-draft count and manual fallback pass rate. Review this entity after adapter or model changes and record the test run under R2. The release cannot claim real provider timing or a production availability rate from fixture evidence.
